Fonts in this folder are open-licensed under the SIL Open Font License (OFL.txt)
and were obtained from the Google Fonts repository (github.com/google/fonts).

To add your own font: drop a .ttf here and add a line to the FONTS table
near the top of SchoolPop.lua, e.g.
  { key = FONT_DIR .. "MyFont.ttf", label = "My Font" },
